# Venezuela: Resource Dependency and Economic Volatility (1960–2023)

## Objective
To analyze how Venezuela’s economic growth has been influenced by its dependence on oil revenues over time.

## Tools Used
- Python (pandas, numpy)
- Jupyter Notebook
- Tableau Public

## Data Preparation
- Cleaned and standardized time-series data
- Created 5-year rolling averages to smooth volatility
- Exported cleaned dataset for visualization

## Key Insights
- GDP growth closely follows oil revenue cycles
- Oil booms contributed to short-term growth but increased long-term vulnerability
- The 2014 oil price collapse coincides with a sharp economic downturn

## Visualization
An interactive Tableau dashboard was created to compare GDP trends with oil dependency metrics.

## Tableau Dashboard
🔗 Interactive Dashboard: https://public.tableau.com/app/profile/omkar.mamidwar2383/viz/VenezuelaResourceDependencyandEconomicVolatility19602023/Sheet1?publish=yes


## Conclusion
This project demonstrates how resource dependency can amplify economic volatility and highlights the importance of economic diversification.
